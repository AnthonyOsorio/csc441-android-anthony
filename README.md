# File Converter
- This app is meant to convert files into specific image files of the users given choice.
## Screens


- **Home**  — User can add and remove files 
- **List**  — User can view included files and chose to keep or remove them.
- **About** — User can get a summary of the app and see developers.
## Input rules
| Input | What the app says |

| (empty) | No response |

| less than 3 characters | Indication stating the input must be at least 3 Characters |

| 30 words or less | Input gets capped at 30 |

| Int values only | Indication stating a name can't be only numbers.

## How to run
1. Clone this repo
2. Open the cloned folder in Android Studio 
3. Wait for Gradle sync, then Run
## Known limitations
- Data does not remain identical when rotating the phone, and rebuilding the screen layout.
- App does not convert files yet.
- App does not allow for file selection from device.
